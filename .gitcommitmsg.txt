Fix ambiguous column references in profile page API

The N+1 optimization used raw SQL column references in subquery JOINs
that rendered without table qualifiers, causing PostgreSQL "column
reference is ambiguous" errors (code 42702). Fixed by using explicit
table-qualified column references in all SELECT fields and JOIN
conditions for the pre-aggregated subqueries.
